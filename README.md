Number Statistics

About the Project

This is a simple Python program that works with a list of numbers. It separates even and odd numbers and finds the largest and smallest numbers in the list.

Objectives

- Identify even numbers.
- Identify odd numbers.
- Find the largest number.
- Find the smallest number.
- Practise Python loops, conditions, and lists.

Technologies Used

- Python
- Jupyter Notebook

How It Works

1. Create a list of numbers.
2. Use a "for" loop to check each number.
3. Use the modulo operator ("%") to separate even and odd numbers.
4. Use "max()" and "min()" to find the largest and smallest numbers.
5. Display the results using "print()".

Sample Output

Numbers: [12, 7, 24, 15, 8, 31, 42, 19, 6, 11]
Even numbers: [12, 24, 8, 42, 6]
Odd numbers: [7, 15, 31, 19, 11]
Largest number: 42
Smallest number: 6
